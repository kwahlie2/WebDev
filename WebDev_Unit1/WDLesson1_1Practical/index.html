Web Technologies

HTML

HTML stands for HyperText Markup Language. It provides the structure and content of a web page using elements such as headings, paragraphs, links, and images. A web browser reads HTML to display that content.

CSS

CSS stands for Cascading Style Sheets. It controls how HTML content looks, including its colors, fonts, spacing, and layout. CSS helps make web pages attractive and usable on different screen sizes.

JavaScript

JavaScript is a programming language used to add behavior to web pages. It can respond to user actions, update page content, and validate forms. JavaScript also powers interactive features such as menus, animations, and games.
